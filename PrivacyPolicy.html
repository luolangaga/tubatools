隐私政策

图吧工具箱CE — 最后更新：2026年10月31日

一、数据收集

图吧工具箱CE 不收集任何可识别您个人身份的信息（姓名、邮箱、电话号码、账号、文件内容、地理位置等）。

为统计活跃用户、定位崩溃与改进软件，应用默认会发送匿名的运行与错误数据，您可以随时在「设置 → 常规 → 发送匿名使用数据」中关闭。

会发送的数据：

  • 运行信息 — 应用版本、Windows 版本与内部版本号、CPU 架构、界面语言、运行模式（便携版 / 微软商店版 / 精简版）、是否以管理员身份运行
  • 匿名设备标识 — 由 Windows 机器 GUID 加固定盐值做 SHA-256 哈希后截断生成的随机字符串，无法反推出您的机器或身份，仅用于区分不同设备（统计活跃设备数 / 在线用户数）
  • 使用事件 — 应用启动、每 10 分钟一次的运行心跳（用于统计在线与活跃设备）、启动的工具名称（工具目录名或内置工具 ID，不含文件路径）
  • 错误日志 — 未处理异常的类型、消息与调用堆栈（其中的用户名与用户目录路径已在本地替换为 <用户>），以及异常来源分类

不会发送的数据：

  • 姓名、邮箱、电话、账号等任何个人身份信息
  • 您的文件内容、文件路径、硬件序列号
  • 键盘输入、屏幕截图、剪贴板内容
  • 用于广告、用户画像或任何商业营销的数据

数据发送至 Axiom（美国东部区域）。除该服务作为托管方外，我们不会将上述数据出售或分享给任何第三方。与所有网络服务一样，接收服务器可能在服务运维日志中记录来源 IP 地址。

二、关闭数据发送

在「设置 → 常规 → 发送匿名使用数据」关闭开关后：

  • 应用立即停止采集，并删除本地尚未发送的待传数据
  • 关闭状态会被记住，后续启动不再发送任何数据

由于采集的数据不包含任何可识别身份的信息，我们无法将已上报的数据定位到具体设备或个人，因此无法针对个人进行删除；如需彻底清除，请在关闭开关后联系我们。

三、数据保留

匿名遥测数据在 Axiom 中保留 30 天，到期后由服务自动清理。

四、本地数据存储

应用仅在您的设备本地存储以下数据：

  • 收藏夹与使用记录 — 您标记为「收藏」的工具路径、启动历史、排序偏好，存储在本地数据目录
  • 图标缓存 — 工具可执行文件的图标提取缓存，存储在 %LocalAppData%\TubaWinUi3\IconCache\
  • 设置与日志 — 界面设置、AI 助手会话与记忆、诊断日志（agent-debug.log 等），存储在本地数据目录

以上数据均保存在您的本地设备上，除「错误日志打包上传」（仅在您手动导出并自行提交时发生）外不会上传。卸载应用时，这些数据可一并清除。

五、网络访问

除匿名遥测外，应用会在您使用相关功能时访问网络，用于：

  • 检查更新与下载 — 从 GitHub / GitCode 等镜像获取应用更新、工具内核与内置工具
  • 元数据与榜单同步 — 获取工具元数据、CPU / GPU 性能榜、社区工具列表
  • AI 助手 — 仅在您自行配置并主动使用时，将对话内容发送至您所配置的 AI 服务商（密钥由您自行填写与保管）
  • 系统镜像下载 — UUP dump 与微软官方镜像源，仅在您主动使用时
  • 游戏联机助手 — Tailscale 网络与登录，仅在您主动使用时

上述网络请求遵循各服务提供方自身的隐私政策。您可以随时在设置中关闭遥测，或通过代理设置控制网络访问。

六、所需权限

应用声明以下权限用于核心功能：

  • runFullTrust — 用于启动第三方诊断工具、读取 WMI 硬件信息、编辑系统 Hosts 文件、管理证书存储、清理系统垃圾文件等系统级操作

七、第三方工具

本应用集成了多个第三方 PC 硬件诊断工具。这些工具作为独立程序运行，各有其自身的功能和数据处理方式。本应用仅提供统一的快捷启动入口，不干涉、不监控这些工具的数据行为。

八、儿童隐私

本应用不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

九、政策变更

如本隐私政策有任何变更，将在应用内及本页面公布。建议定期查阅本页面。

Privacy Policy

Tuba Toolbox CE — Last updated: October 31, 2026

1. Data Collection

Tuba Toolbox CE does not collect any personally identifiable information (name, email, phone number, account, file contents, geolocation, etc.).

To count active users, diagnose crashes and improve the app, the app sends anonymous runtime and error data by default. You can turn this off at any time in Settings → General → Send anonymous usage data.

What is sent:

  • Runtime info — app version, Windows version and build number, CPU architecture, UI language, run mode (portable / Microsoft Store / lite), whether running as administrator
  • Anonymous device identifier — a truncated SHA-256 hash of the Windows machine GUID plus a fixed salt. It cannot be reverse-engineered into your machine or identity and is only used to distinguish devices (active devices / online users)
  • Usage events — app start, a heartbeat every 10 minutes (used to count online and active devices), and the name of a launched tool (folder name or built-in tool ID, never a file path)
  • Error logs — type, message and call stack of unhandled exceptions (usernames and user-folder paths are replaced with <user> locally before sending), plus an error source category

What is never sent:

  • Personal identifiers such as name, email, phone number or account
  • Your file contents, file paths or hardware serial numbers
  • Keystrokes, screenshots or clipboard contents
  • Data used for advertising, profiling or any commercial marketing

Data is sent to Axiom (US East region). Apart from this service as the hosting provider, we do not sell or share this data with any third party. As with any network service, the receiving server may log source IP addresses for operational purposes.

2. Turning Data Collection Off

When you switch off Settings → General → Send anonymous usage data:

  • Collection stops immediately and locally queued, unsent data is deleted
  • The setting is remembered; nothing is sent on future launches

Because the collected data contains no identifiable information, we cannot trace reported data back to a specific device or person, and therefore cannot delete it per individual. To have any data removed, please contact us after switching the setting off.

3. Data Retention

Anonymous telemetry is retained in Axiom for 30 days and is then automatically cleaned up by the service.

4. Local Data Storage

The app stores only the following data locally on your device:

  • Favorites and usage records — favorited tool paths, launch history and sorting preferences, stored in the local data directory
  • Icon cache — extracted icons from tool executables, stored under %LocalAppData%\TubaWinUi3\IconCache\
  • Settings and logs — UI settings, AI assistant sessions and memory, diagnostic logs (e.g. agent-debug.log), stored in the local data directory

All of the above stays on your local device. Apart from the "error report bundle" (which is only uploaded if you export it and submit it yourself), it is not uploaded. It can be removed when you uninstall the app.

5. Network Access

Besides anonymous telemetry, the app accesses the network when you use the corresponding features, to:

  • Check for updates and download — app updates, tool bundles and built-in tools from GitHub / GitCode mirrors
  • Metadata and ranking sync — tool metadata, CPU / GPU performance rankings, community tool lists
  • AI assistant — only when you configure and use it, your conversation is sent to the AI provider you configured (keys are entered and kept by you)
  • Windows image downloads — UUP dump and official Microsoft sources, only when you use this feature
  • Game tunnel — Tailscale networking and login, only when you use this feature

These requests are governed by the privacy policies of the respective service providers. You can turn telemetry off at any time, or control network access through the proxy settings.

6. Required Permissions

The app declares the following capabilities for core functionality:

  • runFullTrust — Required for launching third-party diagnostic tools, querying WMI hardware information, editing the system Hosts file, managing certificate stores, cleaning system junk files, and other system-level operations

7. Third-Party Tools

This application integrates multiple third-party PC hardware diagnostic tools. These tools run as independent programs with their own functionality and data handling. This application only provides a unified launcher and does not interfere with or monitor the data behavior of these tools.

8. Children's Privacy

This application is not directed to children under 13 and does not knowingly collect personal information from children.

9. Policy Changes

Any changes to this privacy policy will be announced within the application and on this page. Please check this page periodically.
