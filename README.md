* **系统优化与安全** —— 垃圾清理 / 启动项管理 / 右键菜单管理 / 恶意软件拦截 / 沙盒分析 / 时间同步
* **网络工具** —— 网速测试 / 流量监控 / 端口占用 / Hosts 编辑 / 局域网文件分享
* **原生 Fluent 体验** —— Mica 材质、圆角窗口、亮暗主题、中英双语界面、全局搜索、收藏拖拽排序
* **工具清单可扩展** —— 把自己的工具丢进 `Tools/` 目录就能被识别，元数据在 `Metadata/tools.json` 里改
* **干净** —— 便携版解压即用，安装版每用户安装；没有常驻后台服务，退出就是真退出

## AI 助手

内置的智能系统代理把「让 AI 直接操作电脑」做进工具箱：它不只回答问题，还能调用系统工具——读取硬件信息、分析磁盘占用、清理垃圾、读写文件、执行命令、联网搜索。

<p align="center">

* **系统级工具调用** —— 内置 28 个 Agent 工具（硬件信息、磁盘分析、进程管理、文件读写、命令执行、联网搜索等），危险操作先弹窗确认
* **完全访问模式** —— 可开关的「完全访问」权限，放开后无需逐条确认，专家用法一气呵成
* **思考过程可视化** —— 推理链（reasoning）流式展示，长回复自动折叠
* **记忆与技能** —— 跨会话记忆（`memory.md`）、技能按会话启用，用得越久越懂你的机器
* **模型自由** —— 内置小图吧自带模型开箱即用，也可接入任意 OpenAI 兼容端点（DeepSeek / OpenAI / 本地模型……）
* **防死循环护栏** —— 重复的工具调用会被拦截，思维链与工具结果有长度上限，连续无进展的循环会被主动终止

## 游戏工具箱

### 游戏监控（覆盖层设计器）

拖拽式设计监控覆盖层：内置多种布局预设，可自由添加 FPS、CPU / GPU 温度与负载、内存占用等组件；游戏中实时显示，也可勾选指标记录数据（最长 2 小时），结束后一次性导出 JSON / Markdown / CSV 报告。

### 系统工具
- **恶意软件拦截器** - 通过将软件厂商证书加入系统不信任列表，阻止流氓软件安装和运行
- **流氓软件的克星** - 扫描和清理流氓右键菜单、自启动、计划任务、服务、浏览器插件和文件关联残留，含恢复中心
- **恶意软件沙盒** - Sandboxie-Plus 沙盒环境，安全运行和分析可疑程序 / 恶意软件，删除沙盒即可还原系统
- **垃圾清理** - 基于 Winapp2 规则库扫描并清理应用缓存、临时文件与注册表残留（引擎来自 FluentCleaner）
- **启动项管理** - 扫描开机自启动项目（注册表 Run、启动文件夹、计划任务、服务等），隐藏微软条目，快速定位异常自启动
- **右键菜单管理** - 管理 Windows 右键菜单项，支持启用 / 禁用 / 编辑 / 添加 / 删除、新建 / 发送到 / 打开方式及 WinX / 现代 / IE 菜单
- **配置修改器** - 修改注册表中的 CPU、GPU、系统等硬件信息显示，支持一键恢复原始配置

## 架构

```
TubaWinUi3.WinUI3/            主程序（WinUI 3 / .NET 10 / Windows App SDK）
  App.xaml.cs                 启动、提权、全局异常兜底
  MainWindow.xaml             自定义标题栏 + NavigationView + Frame，AI 吉祥物常驻顶栏
  Pages/                      各工具页（内置工具、设置、搜索、时间同步、镜像下载……）
  Services/
    BuiltinTools/             47 款内置工具实现（IBuiltinTool + BuiltinToolRegistry）
    Ai/                       AI 助手适配层（TubaChatProvider / AgentToolAdapter / 防死循环护栏）
    GameTunnel/               游戏联机（Tailscale 封装、邀请码、防火墙、端口探测）
    JunkCleaner/              垃圾清理引擎（FluentCleaner.Core 移植 + Winapp2 规则库）
    TimeSync/                 时间同步（w32tm 封装、SNTP 探测、预设服务器）
    ToolCatalog.cs            扫描 Tools/ + tools.json，合并架构变体，生成工具卡片
    HardwareInfoService.cs    WMI / CPU-Z 硬件信息（P/Invoke）
    LiteMonitorService.cs     LibreHardwareMonitor 实时监控（单例）
  Assets/
    BuiltinIcons/             内置工具的彩色矢量图标（按 Fluent System Icons 规范手绘）
    DocEngine/                WebView2 文档引擎（markdown-it / pdf.js / SheetJS / pdf-lib）
  Strings/<lang>/             界面语言资源（zh-CN / en-US）
  Metadata/tools.json         工具元数据的单一事实源（描述 / 排序 / 跨分类 / 内置工具挂载）
TubaWinUI3.BackEnd/           NativeAOT 辅助进程（主动拦截）
TubaWinUi3.Compatible/        .NET Framework 4.8 WinForms 兼容版（旧系统）
TubaWinUi3.Tests/             xUnit 测试（工具目录 / 时间同步 / 联机 / 垃圾清理 / 本地化……）
Tools/                        随包收录的第三方工具（按中文分类目录存放）
installer*.iss · Launcher/    Inno Setup 安装脚本与原生启动器
website-winui3/ · android-tuba-installer/ · file-transfer-web/ · cloudflare-worker/
                              官网 / 安卓安装助手 / 局域网传输 / 联机信令（各自独立工具链）
```

几个值得一提的实现细节：

* **工具清单是数据驱动的** —— `Metadata/tools.json` 是唯一事实源：描述、卡片顺序、跨分类副本、内置工具挂载全在里面；目录本身或其中任一可执行文件被 `match` 命中才会收录，未收录的目录不会展示。
* **只扫描一次，多架构合并成一张卡** —— x64 / x86 / ARM64 变体合并展示，并按当前系统自动选中合适的架构。
* **图标三选一图层** —— 内置工具优先用彩色矢量 SVG，缺图就回退到字体字形，卡片模板三层并存、按需显隐，所以漏配图标只会退回旧样式、不会开天窗。
* **CPU 温度 / 频率 / 功耗走 MSR** —— 依赖 PawnIO 驱动：检测到「已安装但没加载」会自动补启动，仍不可用时给出官方安装引导；FPS 覆盖层则走 ETW 的 `DxgKrnl` Present 事件，不需要驱动。
* **AI 助手有会话级护栏** —— 同会话重复的工具调用第二次直接拦截，思维链与工具结果有长度上限，连续 6 轮纯工具调用且无进展会注入终止指令（`AgentToolLoopGuard`），两套引擎共用。
* **文档转换四引擎逐级回退** —— OfficeCLI 原生渲染逐页截图 → WebView2 文档引擎（pdf.js / SheetJS）→ 纯 C# 转换器 → 本机 Office / WPS COM。
* **垃圾清理是规则库驱动** —— 内置 Winapp2.ini / Winappx.ini 两个规则库，两阶段执行（只读分析 → 真删），离线开箱即用，也能一键更新规则库。
* **快捷方式不用 PowerShell 生成** —— 开始菜单搜索与「发送到桌面」共用进程内的 WScript.Shell COM，避免中文路径经子进程命令行变成乱码。
* **界面多语言即时生效** —— 资源在 `Strings/`，工具元数据用 `Metadata/Tools_<语言>.json` 覆盖层，切换语言不用重启。

## 常见问题

**Q：为什么一打开就弹 UAC？**
烤机、FPS 覆盖层、垃圾清理、时间同步这些功能要读传感器或写系统设置，必须提权。非打包版启动时会统一请求管理员权限；微软商店版按包身份运行，不强制提权。

**Q：里面收录的工具是官方的吗？**
89 款第三方工具版权归各自作者所有，随包分发仅供学习交流，请支持正版；内置的 47 款是本项目原生实现，源码就在这个仓库里。

**Q：能放在 U 盘里随身带吗？**
可以。便携版解压即用，配置默认写在 `%LocalAppData%\TubaWinUi3\`；想在移动硬盘上带着数据走，就在程序目录放一个 `.config_location` 标记文件，配置会改写进程序目录的 `Data\`。

**Q：杀毒软件报警怎么办？**
部分工具具备系统级操作能力（驱动、注册表、清理），可能被启发式引擎误报。官方发布产物由 SignPath 签名，请只从[官方渠道](#安装)下载。

**Q：会不会拖慢电脑？**
没有常驻后台服务：硬件监控只在打开对应页面或游戏覆盖层时运行，监控覆盖层与联机助手退出即结束，不常驻、不偷跑。

**Q：工具打不开 / 提示缺 DLL？**
用「运行库修复」一键补齐 Visual C++ 2008-2026、.NET Framework、DirectX；老格式文档转换需要本机装有 Office / WPS，没装会给出明确提示。

**Q：AI 助手要用哪家的模型？**
内置小图吧自带模型开箱即用，也可以填任意 OpenAI 兼容端点（DeepSeek / OpenAI / 本地模型……），API Key 只保存在本机。

**Q：日志在哪里？**
默认在 `%LocalAppData%\TubaWinUi3\`（便携模式为程序目录的 `Data\`）：`agent-debug.log` 是 AI 助手日志；启动阶段崩溃会记录到 `%TEMP%\app_crash.log`。
