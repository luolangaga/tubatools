===============================================================================
 Display Driver Uninstaller - Issues and solutions
===============================================================================


-------------------------------------------------------------------------------
 1. Stuck in Safe Mode / boot loop (or cannot sign in)
-------------------------------------------------------------------------------

If Windows stays in Safe Mode after DDU:

 Method 1 (recommended)
  1. Boot into the Windows Recovery Environment:
     - boot from a Windows installation USB/DVD, or
     - restart the PC and hold SHIFT until the Advanced Options menu appears.
  2. Open Command Prompt.
  3. Run:

       bcdedit /deletevalue {default} safeboot

     If Windows is not the {default} entry, run "bcdedit" alone to find the
     right identifier (dual-boot systems).

 Method 2 (last resort, only if Method 1 fails)

       bootrec /rebuildbcd

     This rebuilds the boot store; on a dual-boot PC, other entries may need
     to be added back.

 Notes
  - Some UXTheme patchers are known to cause Safe Mode issues.
  - Safe Mode may fail on some systems when CSM is disabled in the BIOS.


-------------------------------------------------------------------------------
 2. DDU does not start
-------------------------------------------------------------------------------

  - Do not run DDU from a network drive.
  - Check that the DDU folder has standard Windows permissions (Full Control)
    for SYSTEM, Administrators and your user account.
  - Try extracting and running DDU from the Desktop.
  - If it still fails, include the log files from the "DDU Logs" folder
    (inside the DDU folder) when asking for support.


-------------------------------------------------------------------------------
 3. An old driver installs itself instead of the new one
-------------------------------------------------------------------------------

Windows Update installs an older driver before you can install yours:

  - Disconnect from the internet before running DDU.
  - Stay offline until your new driver is installed.


-------------------------------------------------------------------------------
 4. Windows still behaves as if it were in Safe Mode
-------------------------------------------------------------------------------

Symptoms: no internet, reduced performance, missing features.

  1. Check that Safe boot is not ticked in msconfig (Boot tab), and that
     "bcdedit" shows no "safeboot" line.
  2. If both are clear, open Registry Editor and go to:

       HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\SafeBoot

  3. If a subkey named "Options" is there, delete it.
  4. Restart the PC.


-------------------------------------------------------------------------------
 5. Laptop: camera missing, features gone, or GPU "Code 31" after reinstall
-------------------------------------------------------------------------------

On laptops, the PC maker ships part of the graphics driver as separate
"extension" packages: panel and power settings on Intel, files the GPU needs
to start on Qualcomm (Snapdragon), colour profiles for the screen (e.g. MyASUS
Splendid). The generic driver from Intel or Qualcomm does not include them.

DDU keeps these extensions by default. If you ticked the "Expert options"
extension removal, or removed the driver another way, you may see:

  - Qualcomm: the GPU shows Code 31 in Device Manager, or the Snapdragon
    Control Panel cannot install the NPU driver.
  - Intel: power or panel settings from the PC maker are gone.
  - The screen shows as "Generic PnP Monitor" and the maker's display modes
    lost their profiles.

To put them back, pick one:

  1. Reinstall the complete driver package from the PC maker's support page
     (not the generic one).
  2. Let Windows Update bring them back (driver updates must be enabled; they
     may show under Optional updates).
  3. From the folder of the extracted package, install the extension .inf
     files: right-click > Install, or run:

       pnputil /add-driver *.inf /subdirs /install

Do not use Device Manager's "Update driver" for extensions: it applies them
to one device only.

To see what is installed:

       pnputil /enum-drivers | findstr /i /c:"Original Name"


-------------------------------------------------------------------------------
 6. Snapdragon Control Panel: a driver download stalls
-------------------------------------------------------------------------------

The Snapdragon Control Panel downloads the drivers from Qualcomm's servers.
After several installs in a row, the servers may slow down or stop answering
for a while, and the download stalls or the panel stops responding. This is
not caused by DDU: close the panel, wait a while, and try again.
