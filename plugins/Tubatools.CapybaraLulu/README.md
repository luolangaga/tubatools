# 水豚噜噜美化包（Tubatools.CapybaraLulu）

给图吧工具箱 CE 换一身软乎乎的外衣。插件以 **fullTrust 动态插件**的方式运行，把装饰叠到主窗口视觉树上：**不修改主程序源码、不修改 Windows 壁纸、不注册内置工具**。停用或卸载时，背景、标题栏图标、侧栏页脚、角落小伙伴、首页贴纸和硬件信息页卡片都会逐项还原。

- 当前版本：**1.3.0**
- 包 ID：`Tubatools.CapybaraLulu`
- 适用：图吧工具箱 CE 1.9.0 / 插件 API v2
- 入口：**设置 → 工具和系统集成 → 插件设置 → 水豚噜噜美化包**

## 1. 放了哪些噜噜

| 位置 | 效果 |
| --- | --- |
| 主窗口背景 | 澡堂 / 草地晒太阳 / 书桌小窝 / 云端晚安四套插画轮换；默认浓度 **45%**，可调 8%–65%，带非常缓慢的漂浮缩放 |
| 侧栏页脚 | 一只打盹的水豚，4 秒呼吸缩放；侧栏变窄时自动缩小图片、隐藏说明文字，不再挤成竖条 |
| 页面右下角 | 角落陪伴噜噜：呼吸、轻微摇摆、说话时弹一下；按页面换表情（首页加油、硬件拿扳手、AI 抱电脑、设置打盹等） |

## 2. 安装与打开设置

1. 打开工具箱的 **插件** 页，安装 `Tubatools.CapybaraLulu.1.3.0.nupkg`。
2. 在插件列表里启用「水豚噜噜美化包」。
3. 打开 **设置 → 工具和系统集成 → 插件设置**，点「水豚噜噜美化包」。
4. 设置会以**设置页内的浮层面板**打开（不是新窗口，也不是内置工具）。点右上角「关闭」或离开设置页即可收起。
5. 在浮层里打开「启用美化包」，按确认弹窗提示操作。
6. 在「背景 / 放在哪里 / 角落小伙伴 / 动效」四组设置里细调；每改一项立即生效并保存。

> 插件**不会**注册 `capybara-lulu` 之类的内置工具 ID，所以「全部工具」、内置工具分类和搜索里都不会多出一张工具卡；唯一入口就是设置页里的这张按钮卡片。

### 3.6 快捷操作

- **一键还原**：先把美化包关掉，再把所有开关恢复默认（总开关保持关闭）。

## 4. 确认与成功弹窗

打开「启用美化包」时：

1. 先弹出**开启前确认**，列出即将发生的变化（背景、侧栏、角落、标题栏、首页、硬件卡片）。
2. 点「取消」：开关自动回到关闭，不产生任何注入。
3. 点「开启」：应用装饰，然后弹「噜噜已就位」成功提示，说明设置入口位置与关闭方法。

设置面板使用**页面内浮层**而不是 `ContentDialog`，所以打开确认弹窗时不会出现 WinUI 不允许的「ContentDialog 套 ContentDialog」问题。

## 5. 恢复与卸载

- **临时收起**：关闭「启用美化包」，所有装饰立即移除。
- **恢复默认外观**：设置面板里的「一键还原」。
- **彻底卸载**：在工具箱插件页卸载；插件停用时 `StopAsync` 会还原视觉树、移除设置页入口和硬件页卡片样式。
- 如果关闭后某一页仍有残留（宿主页面带 `NavigationCacheMode=Enabled`），切走再切回或重启工具箱即可；不会修改主程序文件。

## 6. 权限与运行方式

`tubatools.json`：

```json
{
  "apiVersion": 2,
  "fullTrust": true,
  "permissions": ["background", "appearance", "navigation"]
}
```

- **fullTrust**：需要把装饰插入主窗口视觉树、读写 `AppSettings`、在设置页注入入口。
- **background / appearance**：背景层、主题色和标题栏图标。
- **navigation**：监听页面导航，按页面切换角落表情、在硬件信息页装饰卡片。

插件与工具箱**同进程、同权限**运行；请只安装可信来源的插件。

## 7. 技术说明（给维护者）

- 装饰层挂在 `IPluginHostAccess.RootVisual` 上；背景放在内容区后面，不覆盖标题栏和导航按钮。
- 插件只实现 `IPluginStartup`，`CapybaraPlugin.Register` 是空实现：**不调用 `host.RegisterTool`**，因此没有内置工具条目。
- 设置入口 `CapybaraSettingsEntry` 监听宿主 `NavigationFrame.Navigated`，找到 `SettingsPage` 的 `IntegrationSection`，注入一张带 `AutomationId=CapybaraLuluSettingsEntry` 的按钮卡；带重复检查。
- 点击入口后在 `SettingsPage` 的内容根 `Grid` 上叠一层半透明遮罩 + 居中卡片，卡片内放 `CapybaraPage.View.Root`；关闭/离开设置页时 `Dispose()` 并移除。这样既保持「设置页入口」的体验，又能在浮层内部再弹开启确认 `ContentDialog`。
- 运行层 `CapybaraRuntime` 只依赖 `IPluginHostAccess`，不依赖 `IPluginServices`（没有注册工具就取不到服务）。
- 硬件页装饰 `CapybaraHardwareDecor` 监听导航到 `HardwarePage`，按名称找到 `Card1/2/3` 与包含 `DetailsRepeater` 的 `Border`，保存原始 `Background / BorderBrush / BorderThickness / CornerRadius / Child`，改成本地暖色渐变并插入低透明度噜噜水印；`Restore` 时逐项还原。
- 主题变化时重新计算暖色调；`UISettings.AnimationsEnabled` 与设置里的「动态效果」双开关控制动画。
- 素材从程序集目录上一级的 `assets/` 绝对路径加载，兼容动态插件加载上下文。

## 9. 常见问题

**Q：设置页里点「水豚噜噜美化包」没反应？**  
A：1.3.0 已把入口改为设置页内浮层；若仍无反应，确认安装的是 1.3.0 而不是旧版，并在插件页重新启用。浮层打开失败时会弹出错误提示，不再静默吞异常。

**Q：侧栏收窄后页脚变成一条竖线？**  
A：1.3.0 会在卡片变窄时把图片宽度限制在 34–140 px，并在卡片宽度小于 120 px 时隐藏说明文字；如果仍异常，切走再切回设置页刷新布局。

**Q：硬件信息页的卡片颜色变了，参数会受影响吗？**  
A：不会。只改卡片的 `Background / BorderBrush / BorderThickness / CornerRadius`，并在卡片内容里加一层 `IsHitTestVisible=false` 的水印；参数文本、按钮、3D 全景和滚动都不动。

**Q：背景太浓 / 太淡？**  
A：在「背景浓度」调；默认 45%，建议 35%–55%。旧版默认 26% 会自动迁移到 45%。

**Q：开启确认弹窗能取消吗？**  
A：可以。取消后总开关会自动回到关闭，不会留下半套装饰。

**Q：卸载后还有残留？**  
A：先在插件页停用，再卸载；若宿主页面缓存还留着旧元素，重启工具箱即可。插件不会改动主程序文件。
